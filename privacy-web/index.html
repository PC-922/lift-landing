Privacidad de LIFT Web

Responsable y contacto: PC922 · pcnuevedosdos@gmail.com.

Datos en este navegador

Esta versión no tiene cuenta ni sincroniza con un servidor. Los ejercicios, notas, rutinas y entrenamientos se guardan en el navegador. El almacenamiento del sitio también conserva tus preferencias y los archivos que permiten usar la app sin conexión.

Puedes exportar e importar copias JSON. Pueden incluir notas e historial, y tú eliges dónde guardarlas. Restablecer los datos en Ajustes no borra copias exportadas ni datos que otras versiones hayan guardado. Borrar los datos del sitio puede eliminar tu historial local.

Alojamiento y contacto

La app se sirve desde GitHub Pages. GitHub registra direcciones IP para fines de seguridad. Consulta la información sobre datos de GitHub Pages. Si escribes a soporte, PC922 usa tu correo y mensaje para responder. No envíes información médica ni historiales completos si no son necesarios.

Puedes contactar con PC922 para ejercer tus derechos de protección de datos, cuando procedan, o para consultar sobre datos de versiones anteriores. También puedes reclamar ante la Agencia Española de Protección de Datos.

LIFT Web Privacy

Controller and contact: PC922 · pcnuevedosdos@gmail.com.

Data in this browser

This edition has no account and does not sync with a server. Exercises, notes, routines and workouts are stored in your browser. Site storage also keeps your preferences and the files needed for offline use.

You can import and export JSON backups. They may contain notes and history, and you choose where to save them. Resetting data in Settings does not delete exported copies or data stored by earlier editions. Clearing site data can remove your local history.

Hosting and contact

The app is served from GitHub Pages. GitHub logs IP addresses for security. See GitHub Pages data collection. If you contact support, PC922 uses your email address and message to respond. Please do not send medical information or complete workout histories unless necessary.

Contact PC922 to exercise applicable data protection rights or ask about data from earlier editions. You can also complain to the Spanish Data Protection Agency.
